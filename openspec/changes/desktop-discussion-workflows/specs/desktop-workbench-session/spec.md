# Desktop 会话与配置

## Purpose

F012 接收既有 Desktop 适配草案中尚未整体完成的会话、目标绑定、客户端入口及配置迁移要求。已交付的冷会话或连接兼容仅是局部证据；本能力仍需具体版本确认和联合验收，不取代当前主规格。

## ADDED Requirements

### Requirement: F012 冷会话和场景默认

工作台 SHALL 从真实会话头恢复 cwd 和持久状态，首次工具或上下文访问不依赖 UI hello。场景允许 meeting、project、thinking，旧数据和新会话默认 meeting；只有 scene 字段不得算作使用痕迹。

#### Scenario: 未打开界面的冷会话

- **WHEN** 首次调用工具时客户端尚未连接
- **THEN** 使用宿主会话真实 cwd 恢复状态；不能使用空工作区、其他会话路径或强制唤起面板。

#### Scenario: 旧状态缺少新场景字段

- **WHEN** 恢复旧数据或新建会话
- **THEN** 保持 meeting 默认，普通聊天不因此视为已使用工作台。

### Requirement: F012 固定目标的宿主租约

工作台 SHALL 显式领取文档服务的会话绑定租约，以串行操作维护绑定、持久目标及会议角色；解绑包括 pinned=null。浏览候选不改变目标；页面断开不释放宿主租约，插件或会话销毁才释放。

#### Scenario: 绑定中途失败

- **WHEN** 文档绑定、目标保存或会议角色更新任一步失败
- **THEN** 恢复原绑定和状态，或明确返回不能写入的失败，绝不将未知目标作为后续编辑对象。

#### Scenario: 页面断开

- **WHEN** 仍有效的会话关闭一个页面或全部页面
- **THEN** 固定目标不丢失；仅最后连接断开后清理该会话的面板显示记忆。

### Requirement: F012 Desktop 通信信任边界

客户端 SHALL 使用宿主公开会话属性和路由／流地址；仅接受宿主实际可信来源及明确的 dsh-app://app，不信任 null 或外部网页来源。消息必须校验类型与当前会话绑定，不允许 payload 冒充另一会话。

#### Scenario: 伪造来源或会话

- **WHEN** 外部来源或当前连接携带其他 sessionId
- **THEN** 拒绝请求且不改变目标、配置或材料；正常 Desktop 入口无需猜测窗口 URL。

### Requirement: F012 配置继承与所有者唯一

dockMode SHALL 仅接受 auto／always／off，并沿用用户覆盖→组装值→默认优先级。配置页只编辑完整包名对应的唯一实际条目，缺失或多条不得猜选。用户修改即时生效且不重挂插件、不丢失在途绑定；继承值不得自动物化为覆盖。

#### Scenario: 编辑唯一所有者

- **WHEN** 找到实际唯一条目并保存当前草稿
- **THEN** 按固定配置版本更新并显示新有效值；其他面板草稿与在途文档操作保留。

#### Scenario: 所有者不唯一

- **WHEN** 没有条目或有多个可能所有者
- **THEN** 界面说明不可编辑，禁止选择第一项写入。

### Requirement: F012 非法旧值与可选设置服务

旧非法 dockMode SHALL 按已有预期降级 auto 并告警；应验证真实插件装载路径，不以伪造 ctx 测试掩盖 schema 前置拒绝。可选设置服务缺失只影响配置卡，不阻止工具、材料和会话能力挂载。

#### Scenario: 旧配置非法

- **WHEN** 真实宿主装载含非法旧 dockMode 的数据
- **THEN** 插件仍提供核心能力并报告一次降级告警，不崩溃也不静默采用任意其他模式。

### Requirement: F012 显式配置迁移和恢复

旧设置迁移 SHALL 先预览再显式执行，按快照版本校验并备份，只处理本插件拥有的 dockMode，保留未知字段并报告。失败只恢复自身写入集合；并发变化须报冲突，不覆盖较新数据。

#### Scenario: 迁移后并发修改

- **WHEN** 预览后配置被其他客户端改变
- **THEN** 执行拒绝冲突且不写入；成功迁移仅清理确认已迁走的旧字段，不删除整个未知命名空间。

#### Scenario: 应用或恢复失败

- **WHEN** 执行迁移或恢复遇写入错误
- **THEN** 保留可定位备份和明确错误，部分结果不宣称全部成功，不回滚别人的新改动。
