# 通用工作台工具与会议工具指引

## Purpose

2026-10-18 讨论版 workbench-tool-groups-20261018-v1 仅提出职责分类和 Skill 组织建议；当时确认仅覆盖名称及套件交付，未批准改工具、运行 Skill 或业务流程。 本文件保留原始讨论的使用边界、开放问题与可验证情形；全部属于待确认待实现的增量，不能因为迁移或格式校验通过而视为运行能力。

## ADDED Requirements

### Requirement: 通用与会议职责分组

指引 SHALL 把状态、上下文、材料读取和来源搜索归为通用职责，把打开会议和维护会议信息归为会议扩展；职责分组不表示新增 general 场景、自动分类或动态隐藏工具。

#### Scenario: 仅把会议文档当材料

- **WHEN** 项目讨论引用一份会议记录
- **THEN** 使用通用材料流程，不仅因为出现“会议”二字自动打开会议任务。

### Requirement: 按明确任务使用工具

指引 SHALL 在普通聊天时直接讨论，接续任务或写入前按需核对目标／版本，目标不变不每轮重复 set；登记不等于读过，引用所需正文须分页读取。只有明确落稿意图后调用文档写入工具。

#### Scenario: 继续已有任务

- **WHEN** 固定目标保持且用户继续讨论
- **THEN** 沿用已有上下文，缺材料才读或搜索；写入前确认实际目标与版本，不重复初始化会议。

### Requirement: 单份技能分段与名称过渡

Skill 组织方案 SHALL 优先在一份技能内分为是否需要工作台、通用流程、会议扩展，避免复制共同规则。若通用检索工具改名，必须另行确认注册、调用引用与旧名过渡；当前不新增别名或承诺全文搜索。

#### Scenario: 评估通用检索名称

- **WHEN** 准备把 search_meeting_source 改为通用名称
- **THEN** 先确定兼容方案并同步所有引用；在未获确认前保留现名及现有范围，职责分类不改变运行注册。
