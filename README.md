管理参考材料、固定目标文档，联动结构化文档、视图和侧边栏工具，支持 Agent 在讨论中整理与修改文档。

## 能做什么

- 为当前会话登记参考文件或粘贴文本，按需读取材料内容。
- 固定本次要整理的目标文档，查看其他材料时保持目标，减少改错文件的机会。
- 在输入框上方显示材料数量、目标、当前节点和最近改动，与 Agent 获得的工作台上下文对应。
- 打开会议目录、维护会议信息，或以项目场景组织材料与目标；普通讨论不会自动写入文档。

### 和其他插件怎样配合

| 插件 | 负责什么 |
|---|---|
| dsh-structured-document | 文档结构、内容修改、保存与撤销 |
| dsh-structured-document-view | Markdown／思维导图／表格展示和视图切换 |
| dsh-better-sidebar-controller | 文件浏览与侧边栏状态控制 |
| 本工作台 | 组织目标、参考材料、上下文和修改反馈 |

工作台随包注册一份 `discussion-workbench` 技能和六个模型工具，帮助 Agent 组合以上能力。插件间还可调用工作台服务。本插件不自行运行模型，也不复制其他插件的文档内核。

## 安装

当前本地版本 **0.2.1-rc.2+rev.1**，适配 **DSH Desktop 0.2.1-rc.2**。先安装并启用以下组合：

- **Better Sidebar 0.28.0**；
- **dsh-better-sidebar-controller 0.2.1-rc.2+rev.1**；
- **dsh-structured-document 0.2.1-rc.2+rev.1**；
- **dsh-structured-document-view 0.2.1-rc.2+rev.1**。

截至 2026-10-18，[公开源码仓库](https://github.com/irvingzhang0512/dsh-discussion-workbench)默认分支包版本为 **0.1.1**，本页版本尚未公开推送或发布。先向维护者获取当前组合的完整预构建包，目前没有本版公开下载链接。

1. 核对前置插件和宿主版本，先完成它们的安装与启用。
2. 在「插件 → 添加插件 → 安装第三方插件」填写本工作台 `.tgz` 的本机绝对路径，核对包名和版本后启用，按提示重启 DSH。
3. 在真实工作区会话中按下面的首次使用步骤登记材料，检查摘要栏是否出现。新建的普通会话默认不显示摘要栏。

本版隔离 Desktop 联调范围见 [兼容记录](docs/DSH-UPGRADE-20261017.md)。首次公网安装、真实模型与外部转换服务不因这份文档而视为已验收。

## 配置

第一次使用无需修改配置。摘要栏默认按需显示：有整理目标、参考材料或已打开会议时出现。

| 摘要栏策略 | 值 | 效果 |
|---|---|---|
| 按需，默认 | `auto` | 使用工作台的会话显示 |
| 始终 | `always` | 所有会话显示 |
| 不显示 | `off` | 隐藏摘要栏，工具与已使用会话的上下文仍可用 |

在 Desktop 插件详情查看对应组件的 `dock` 配置，组装层修改需重载。历史独立即时设置卡依赖旧设置服务，缺失时不显示，仍可使用默认值与组装配置；不要把旧 Web 设置卡路径当作所有 Desktop 的统一入口。详细层级见 [技术架构](docs/architecture.md)。

## 第一次使用

在一个真实工作目录的会话中，用一段已知材料完成「讨论 → 创建目标 → 修改」：

1. 发送：

   > 使用 discussion-workbench 技能，把下面的文字登记为参考材料，先讨论，不写文件：下周准备安排一次项目评审，具体时间和参会人尚未确认。

   输入框上方应出现摘要栏，参考材料数量增加；此时没有目标文档是正常状态。
2. 明确要求落稿：

   > 在当前工作区根目录新建项目模板的“评审准备”文档，包含“已知安排”和“待确认”两节。根据刚才材料整理，未确定的信息保持待确认。不要覆盖已有文件，将实际新建文件固定为本次整理目标。

   核对返回的实际路径与保存结果，摘要栏应显示同一个目标文件；打开文档检查内容。
3. 继续说「在待确认中补充评审资料清单尚未确定，合并为一次修改」。展开摘要栏核对最近改动和文档版本。
4. 需要撤销时点击「撤销整次修改」，核对刚才补充的内容已撤回，其他内容保留。可在展开面板切换三种视图查看结果。

整个流程中，材料是依据，目标是写入位置。Agent 需要实际读取材料；登记成功不等于已经读过全文。

## 常用操作

| 想做什么 | 怎么做 | 结果 |
|---|---|---|
| 添加文件材料 | 先列出真实工作区文件，再在展开面板填写实际路径或让 Agent 登记 | 材料列表增加，按需读取正文 |
| 换整理目标 | 在展开面板填写实际 Markdown 路径，点击「固定目标」 | 后续文档操作绑定新目标 |
| 浏览参考文件 | 用侧边栏打开材料 | 固定整理目标保持不变 |
| 管理一场会议 | 提供真实会议目录，通过面板或 Agent 打开会议并维护信息 | 识别已有固定名记录／纪要，恢复该会议状态 |
| 只讨论方案 | 明确先讨论、不修改 | 保留讨论过程，不自动改写文档 |

## 使用边界

- 当前场景只有会议和项目。工具分类、独立思路场景、更多双稿／项目工作流属于后续设计，尚未因本次 README 更新而实现。
- 目标支持工作区内的 `.md`／`.markdown`；文件材料支持 `.md`／`.markdown`／`.txt`／`.json`。路径需真实存在并通过工作区检查。
- 材料正文按需分段读取。当前来源搜索每份材料只检查前 20000 字符；没有命中不等于全文没有，应让 Agent 继续分段读取。
- 会话状态与粘贴材料保存在工作区 `.dsh-workbench/` 下，会议元信息可保存在会议目录 `.meeting-workbench.json`；原文档仍由文档插件保存。
- DOCX 导入和 PDF 导出已有外部流程，但依赖额外转换脚本、PowerShell 或浏览器程序，不是开箱即用的内置格式转换。使用前按 [会议操作指南](docs/voice-meeting-minutes-guide.md)核对条件。
- 固定目标、材料与节点按会话隔离。写入前核对目标和当前版本；目标绑定异常时先恢复绑定。

## 常见问题

### 安装后为什么看不到摘要栏

默认按需显示。先登记材料、设置整理目标或打开会议；仍不显示时，检查插件及三个协作服务是否运行、当前会话连接是否正常，以及 `dock` 是否设为 `off`。

### 打开了另一个文件，为什么目标没变

这是固定目标的用途，方便边看参考材料边修改同一份主文档。要换写入位置，请明确重新固定目标，并检查摘要栏路径。

### 工具、Skill 和工作台服务有什么区别

工具执行具体动作；Skill 说明 Agent 何时读取材料、核对目标或写入；服务给其他插件调用。文档修改与视图切换由对应插件执行，不重复计算为工作台自己的工具。完整说明见架构与源码入口。
