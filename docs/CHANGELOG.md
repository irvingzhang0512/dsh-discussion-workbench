# 更新记录

## 0.2.0（2026-10-10）

- 新增宿主配置 `dock`（`always` / `auto` / `off`，默认 `auto`）：摘要栏默认只在该会话已使用工作台（已有固定整理目标、参考材料或已打开会议）时出现，不再在任何会话常驻。
- 工作台上下文注入改为只跟随会话是否已使用：未使用的会话不再注入 `[讨论工作台上下文]` 文本块，`dock` 取值不影响注入条件。
- 会话一旦显示过摘要栏，本次连接内保持显示，避免解除目标或删空材料时面板中途收起；连接断开后按当时痕迹重新判定。
- 配置取值非法时按 `auto` 处理并记录警告，不中断插件挂载；六个工具与技能始终注册。
- 新增 `tests/dock.spec.ts` 与 `tests/host-context.spec.ts`；`npm run typecheck`、`npm test`（26 项）、`npm run build` 通过。未做真实宿主与页面验收。
