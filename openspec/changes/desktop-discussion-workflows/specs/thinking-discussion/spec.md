# 讨论到文档

## Purpose

F013 保留普通讨论不自动写文件、明确整理意图后才创建固定目标、成组修改保持未涉及内容的要求。它是尚未批准的 thinking 场景增量，不把现有 meeting 或 project 的行为改写成已经实现的新场景。

## ADDED Requirements

### Requirement: F013 普通讨论不建立文档任务

普通问答和头脑风暴 SHALL 直接讨论；未出现材料或文档任务时不得为了聊天每轮调用状态读取、建立工作台或自动创建文档。明确整理或落稿后才使用文档创建并固定实际保存路径。

#### Scenario: 从聊天转为落稿

- **WHEN** 多轮讨论后用户明确要求整理成文档
- **THEN** 创建并确认实际保存位置后绑定目标，之前的普通讨论没有隐式文件写入。

### Requirement: F013 批量修改与指代保护

成组修改 SHALL 在明确目标、版本和节点下作为单次事务与撤销处理，保留未要求修改的内容和稳定节点 ID；“这个”等指代不能唯一定位时必须澄清，不猜节点。

#### Scenario: 局部改写或重排

- **WHEN** 用户仅要求改一组明确段落
- **THEN** 只修改指定内容，未涉及节点 ID 与正文保留；一次撤销恢复该批修改。

### Requirement: F013 已保存但未登记的恢复

创建文档保存成功但工作台登记失败时 SHALL 返回已保存路径和部分失败状态；重试应登记现有文件，不重复创建另一份文档。

#### Scenario: 登记故障

- **WHEN** 创建操作已把文档落盘而上下文保存失败
- **THEN** 保留文件并告知 saved_path 和后续登记步骤，不把结果写成完全失败后自动再创建。
